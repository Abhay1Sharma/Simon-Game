# 🧠 Simon Game

A web-based implementation of the classic electronic **Simon** memory game. Test your short-term memory and pattern recognition skills!

---

## 🕹️ How to Play

The objective is to repeat the sequence of colored lights and sounds generated by the game.

1.  **Start the Game:** Press any key on your keyboard **(or click the 'Start' button, if your design includes one)** to begin.
2.  **Watch and Listen:** Simon will display a sequence of one or more colors, flashing them one at a time.
3.  **Repeat the Sequence:** Click the colored buttons in the *exact same order* as they flashed.
4.  **Advance:** If you successfully complete the sequence, you move to the next level, where the sequence gets one step longer.
5.  **Game Over:** If you click the wrong color, the game ends. **The final screen will display your score/highest level achieved.**

---

## ✨ Features

*   **Classic Gameplay:** Faithful recreation of the original Simon game logic.
*   **Progressive Difficulty:** The sequence increases by one step with each successful level.
*   **Visual and Auditory Feedback:** Buttons flash and play a distinct sound when part of the sequence or when clicked by the user.
*   **Game Over State:** **Clear visual and auditory indication of game failure.**
*   **Technology Stack:** Built using **HTML5, CSS3, and Vanilla JavaScript (or specify if you used jQuery/other libraries).**
